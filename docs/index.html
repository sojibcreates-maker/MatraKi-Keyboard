Complete Setup Process

How to Install & Use MatraKi (Step-by-Step)

Select your operating system below to see the exact installation and activation steps.

1
Download the Official .deb Package

Run this command in your terminal (or download directly from the Download section above):

wget https://github.com/sojibcreates-maker/MatraKi-Keyboard/releases/download/v1.0.0/matraki-keyboard_1.0.0_amd64.deb
2
Install the Package via APT

APT will automatically install fcitx5 and required Qt5 libraries alongside MatraKi:

sudo apt update && sudo apt install -y ./matraki-keyboard_1.0.0_amd64.deb
3
Start MatraKi & Toggle Bangla Typing

Launch MatraKi from your Application Launcher (or run /usr/share/matraki-keyboard/matraki-gui). Press Ctrl + Space in any app to switch between English and Bangla!

1
Download & Make Executable
wget https://github.com/sojibcreates-maker/MatraKi-Keyboard/releases/download/v1.0.0/MatraKi-Keyboard-1.0.0-x86_64.AppImage
chmod +x MatraKi-Keyboard-1.0.0-x86_64.AppImage
./MatraKi-Keyboard-1.0.0-x86_64.AppImage
1
Install directly on Fedora / RHEL / openSUSE
sudo dnf install -y fcitx5 qt5-qtbase zstd
sudo rpm -Uvh https://github.com/sojibcreates-maker/MatraKi-Keyboard/releases/download/v1.0.0/matraki-keyboard-1.0.0-1.x86_64.rpm
1
Download & Run the Windows Setup .exe

Download MatraKi-Keyboard-1.0.0-Setup-x86_64.exe (or 32-bit i386.exe), double-click to open the setup wizard, and choose either Install MatraKi Keyboard Suite or Run Portable Mode.

1
Clone & Run the Automated install.sh Script

Works on standard Linux distributions as well as immutable desktops like Deepin Linux:

git clone https://github.com/sojibcreates-maker/MatraKi-Keyboard.git
cd MatraKi-Keyboard
chmod +x install.sh
./install.sh
Engineered for Speed & Accuracy

What Makes MatraKi Smarter?

Every component of MatraKi was crafted to eliminate repetitive keystrokes and make Bengali writing natural.

🧠
20,535+ Trained Words & Suffix Stemmer

Type complex words and inflected nouns effortlessly. MatraKi’s agglutinative stemmer automatically attaches -গুলো, -দের, -টা, -টি, -কে, -তে, -ের to any root noun in O(1) time.

🔮
Context-Aware Next-Word Prediction

Right after pressing Space, MatraKi suggests natural follow-up words from 130+ conversational contexts and ranks verb endings based on the subject pronoun (আমি করব, তুমি করবে, আপনি করবেন).

✅
Bangla Academy Grammar & Spelling Fix

Automatically detects and fixes common Nattvabidhi (ণ-ত্ব), Shattvabidhi (ষ-ত্ব), and vowel-length mistakes (সান্ত্বনা, ইতোমধ্যে, পুরস্কার, পরিষ্কার, শারীরিক, সমীচীন).

🧮
In-Keyboard Calculator & Unit Converter

Type =500*15% for instant math results in Bangla digits and words, or convert units on the fly: =10km, =5kg, =100c, =5ft, =1bigha, =5katha.

⚡
Instant Chat & Islamic Snippets (!)

Type !salam, !olikum, !bismillah, !alham, !insha, !shokal, !eid, or !jumma and press 1–9 to commit full greetings in Bangla or Arabic.

📅
All 31 Date Ordinals, Currency & Emojis

Type 1la through 31she (১লা, ২১শে, ২৬শে, ৩১শে), 500tk (৫০০ টাকা / ৳৫০০ / পাঁচ শত টাকা), @today, or :smile without switching keyboards.

Got Questions?

Frequently Asked Questions (FAQ)

1. Which is the best Bangla phonetic keyboard for Linux (Ubuntu, Deepin, Mint, Fedora)?＋

MatraKi v1.0.0 is purpose-built for modern Linux desktops running Wayland or X11. Unlike older keyboards that lag or fail in modern apps, MatraKi integrates natively with Fcitx5 and IBus, and comes pre-trained with 20,535+ Bengali words, next-word prediction, and 6 popular layouts (Avro Phonetic, Probhat, National/Jatiya, Munir Optima, Borno, and Avro Easy).

2. How do I switch between English and Bangla while typing?＋

Simply press Ctrl + Space on your keyboard at any time, or click the language button on the floating MatraKi TopBar pill on your desktop. In addition, if you type a capitalized tech or brand word like Facebook, Google, GitHub, or Linux while in Bangla mode, MatraKi’s Hybrid English detector offers the English word directly in your candidate list!

3. How do I type Bengali Dari (।) quickly?＋

Press the Spacebar twice quickly (Double Space) after finishing a sentence—MatraKi automatically converts the double space into a Bengali Dari followed by a space (। ), just like modern smartphone keyboards.

4. How can I add my own custom words or phonetic replacements?＋

Open MatraKi Settings → Dictionary (Auto-Correct). You can use the instant search bar to filter through all 20,535+ trained entries or add your own custom phonetic pattern with live Bangla preview.

5. Is MatraKi completely free and open-source?＋

Yes! MatraKi is 100% free and open-source software licensed under the GNU General Public License v3.0 (GPL-3.0). You can inspect the code, contribute, or support the developer via SupportKori.
